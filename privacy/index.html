This Privacy Policy describes how TapTags ("the App") handles information when you use it.

Summary

TapTags is designed to program NFC tags with a phone number and an optional 4-digit lock code so others can contact you by tapping the tag. The App is built to keep that process local to your device and the physical tag.

Information we process

Information you provide

  • Phone number you enter to write onto an NFC tag
  • 4-digit lock or unlock code you set to protect a tag from being rewritten by others

These values are used only to prepare NFC (NDEF) payloads and interact with tags you choose to scan.

Information stored on NFC tags

When you write a tag, the phone number and lock-related data are stored on the physical NFC tag, not on TapTags servers. Anyone who can physically tap the tag may be able to read the contact action encoded on it (for example, opening a phone dialer). Protect tags accordingly.

Information we do not collect

As of the date above, TapTags does not:

  • Create user accounts
  • Upload your phone number or lock code to our servers
  • Sell personal information
  • Show third-party advertising
  • Use analytics SDKs that report identifiable usage (unless a future version discloses otherwise)

If a future version adds analytics, crash reporting, cloud sync, or accounts, this policy will be updated before those features ship.

Permissions

NFC: used to read and write NFC tags. On Android, NFC hardware is required for installation. On iOS, NFC is used via Core NFC when you choose to program a tag.

Data retention

The App does not operate a backend database of your contact numbers. Data you write resides on NFC tags you control. Clearing app storage on your device removes locally cached UI state, if any; it does not erase tags you already programmed.

Children's privacy

TapTags can be used to label children's belongings, but the App is not directed at children under 13 as end users who create accounts. Do not encode sensitive personal data beyond a contact number you are comfortable sharing via a physical tap.

Third parties

If you open a phone dialer or another system app after tapping a tag, that interaction is handled by your device OS and carrier under their own terms.

Your choices

  • Do not write a number you do not want others to call
  • Use the lock code feature to reduce the chance others rewrite your tag
  • Wipe or overwrite a tag if you no longer want it to share your number

International users

Processing occurs on your device and on tags you present to it. We do not intentionally transfer TapTags contact data to other countries because we do not host that data.

Changes

We may update this policy. The "Last updated" date will change when we do. Continued use of the App after an update means you accept the revised policy.
