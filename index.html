How it works

Set up a tag in a few steps, then anyone who taps it can reach you.

  1. Open TapTags

    Start the app on your phone.

  2. Enter your number

    Choose the phone number you want to share.

  3. Set a lock code

    Add a 4-digit code so others cannot rewrite your tag.

  4. Hold your phone near the tag

    TapTags writes the details straight to the NFC tag.

  5. Done

    Anyone who taps the tag can call you. They do not need TapTags installed.

Compatibility

Requires an NFC-enabled iPhone (7 and later, iOS 15.0+) or an Android phone with NFC hardware (Android 7.0+). Works with common writable NFC tags such as NTAG213, NTAG215 and NTAG216.
